
# ClariFi Frontend (Vue 3 + Vuetify + Vite)

This project uses Vue 3, Vuetify, and Vite for the frontend.

## Getting Started

1. **Install dependencies:**
	```sh
	npm install
	```
2. **Run the development server:**
	```sh
	npm run dev
	```
3. **Build for production:**
	```sh
	npm run build
	```
4. **Build using script:**
	```sh
	./start_clarifi.sh
	```

## Project Structure
- `src/` — Vue source code
- `start_clarifi.sh` — Build script

## Customization
- Modify `src/App.vue` for your main layout.
- Add Vuetify components as needed.

---

For more info, see [Vuetify docs](https://vuetifyjs.com/) and [Vite docs](https://vitejs.dev/).
